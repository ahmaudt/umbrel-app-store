# BedeBooks Umbrel App Store

An Umbrel Community App Store with one app, BedeBooks: a self-hosted audiobook library.

In umbrelOS, open **App Store › ⋯ › Community App Stores**, add

```
https://github.com/ahmaudt/umbrel-app-store
```

and install **BedeBooks**. Put audiobooks in **Files › Downloads › audiobooks**, then open BedeBooks on port 9333. The first account you create becomes the admin.
